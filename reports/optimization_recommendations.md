## 2. 梳理出的核心优化空间与迭代需求清单
### [P0] OPT-001: 长上下文 Prompt Cache 预计算与复用机制
- **分类**: 性能与延迟优化
- **详细说明**: 针对多轮对话与智能体长任务研发，对 System Prompt 与通用上下文建立客户端 Hash 预缓存，大幅降低首字延迟 (TTFT) 达 30%-50%。
- **预期收益**: 首字延迟从 780ms 降低至 350-450ms，显著提升 Agent 响应体感。

### [P1] OPT-002: 提示词自适应压缩与历史折叠算法
- **分类**: Token 经济性与上下文管理
- **详细说明**: 在超长对话跨越多轮调用时，自动对前序非核心工具调用日志进行语义摘要或修剪，压缩输入 Token 规模，规避超长窗口截断。
- **预期收益**: 节省 25%-40% 上下文 Token 消耗，减少网页端单次传输超时风险。

### [P0] OPT-003: 冷热模型动态负载均衡与自适应降级矩阵 [COMPLETED / 已落地]
- **状态**: COMPLETED (已落地)
- **分类**: 高可用与调度优化
- **详细说明**: 结合当前 FailoverRouter，引入滑动窗口探测各 Provider 的实时并发与速率限制，在高峰期对轻量查询自动分流至 Flash / Lite 模型。
- **预期收益**: 消除 429 频控雪崩，网关整体吞吐量提升 60% 以上。

### [P2] OPT-004: 思考流 (Thinking Stream) 增量语法高亮与折叠加速
- **分类**: 协议与体验增强
- **详细说明**: 优化前端 index.html 与 Anthropic 思考块流式分包策略，使推理过程平滑呈现且支持客户端实时进度条提示。
- **预期收益**: 提升复杂研发任务下的开发者端到端交互感知与调试透明度。
